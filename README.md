# Granada Cultura

Agenda cultural personal de Granada.

## Publicar con GitHub Pages

1. Sube todos los archivos a la raíz del repositorio.
2. En GitHub entra en `Settings > Pages`.
3. Selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Pulsa `Save`.

`eventos.json` queda preparado para la siguiente fase: importar eventos reales.
Los favoritos, estados y notas privadas se guardan en el navegador del dispositivo.
